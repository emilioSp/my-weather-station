## Objective

Display and monitor the Raspberry Pi's CPU temperature in the application. The [deployment guide](../deployment.md) already documents a manual temperature check, but that
is not an application monitoring feature. Collection, history, and presentation details remain open.

## Completed When

Not yet defined. The owner must decide which CPU temperature data to collect and how it should appear.
